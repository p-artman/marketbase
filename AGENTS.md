# AGENTS.md — ПРАВИЛА И СТАНДАРТЫ ДЛЯ AI-АГЕНТОВ (MARKETBASE)

> **СТАТУС:** Обязательный регламент для всех AI-агентов и разработчиков библиотеки `marketbase`.
> Репозиторий представляет собой переиспользуемую базовую библиотеку маркетплейса: DTO, абстрактные модели Django, сервис-провайдеры оплат (ЮKassa 54-ФЗ), доставки (СДЭК API v2), мессенджеров (Telegram, MAX Messenger) и уведомлений.

---

## 1. МОДУЛЬНЫЙ КОНТЕКСТ И СТРУКТУРА

1. **Изолированность ядра:**
   - Код ядра библиотеки находится в `src/market_base/`.
   - Внешние адаптеры обратной совместимости — в `src/bsl_core/`, `src/bsl_delivery/`, `src/bsl_messengers/`, `src/bsl_payments/`, `src/bsl_notifications/`.
   - Тесты находятся в `tests/`. Примеры — в `examples/`.
2. **Безопасность:**
   - Никаких секретов, токенов и ключей в коде и репозитории.
   - Тесты используют моки или официальные песочницы с безопасными fallback-значениями.

---

## 2. ПРАВИЛА ВЕТВЛЕНИЯ И PULL REQUEST (PR.md / PULL_REQUEST.md)

1. **Обязательный файл PR в ветке:**
   - При работе в любой рабочей ветке по результатам правок создаётся файл `PULL_REQUEST.md` в корне репозитория.
   - Файл должен содержать:
     * **Заголовок PR (Title):** ёмкий заголовок по стандарту Conventional Commits (например, `feat(core): add warehouse model and improve CDEK suggest API`).
     * **Тело сообщения PR (Description/Body):** мотивация, список решённых задач, перечень изменений по модулям, результаты тестов и чеклист проверки.
2. **Актуализация при каждой доработке:**
   - При внесении любых изменений или новых коммитов внутри ветки заголовок и тело сообщения в `PULL_REQUEST.md` **обязательно актуализируются**, чтобы отражать полный и актуальный состав Pull Request.
